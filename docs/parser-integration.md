# YouTube → парсер → CEFR

```bash
python -m pip install ".[parser]"
python parser_test.py "https://www.youtube.com/watch?v=uVGV8LG3HHM"
```

Опційні залежності — `youtube-transcript-api>=1`, `serpapi` та `python-dotenv`. Базовий
аналізатор і локальні перетворення парсера працюють без них. `transcript_parser`
включено до зібраного wheel. Для SerpApi fallback потрібна змінна середовища
`SERPAPI_KEYS` з ключами через кому; без неї основний YouTube-провайдер працює,
а спроба fallback повертає явну помилку. Помилки провайдерів логуються,
ключі не виводяться.

За наявності `python-dotenv` змінні також завантажуються з `.env` без
перезапису вже заданих змінних середовища. Без цієї бібліотеки можна задати
`SERPAPI_KEYS` безпосередньо в середовищі.

```python
from transcript_parser import get_transcript
from cefr_analyzer import Analyzer

analyzer = Analyzer()
word_dict, text = get_transcript(url, language="en")
report = analyzer.analyze(text=text, words=word_dict)
print(report["assessment"]["level"])
print(report["word_levels"])
```

Сигнатура результату парсера збережена:

```python
({"word": ["She", "turned", "it", "down."],
  "time_code": [0.0, 0.375, 1.125, 1.375]},
 "She turned it down.")
```

Словник можна передати напряму, перетворити на DataFrame або на список
записів. Аналізатор перевіряє рівність довжин колонок і нормалізованих слів.
Вихідний контракт CEFR v1.0 не змінено.

Текст збирається з тих самих очищених словесних фрагментів, що й таблиця.
Числа, акцентовані літери та Unicode-пунктуація не відкидаються. Декодуються
HTML-сутності, прибираються підтримувані теги, музичні позначки й `[Music]`.
Межі сегментів субтитрів не стають крапками: `turned | out` і
`must have | been working` зберігаються як єдині конструкції.
Фактична пунктуація джерела зберігається. Відсутня пунктуація не відновлюється.

Якщо англійської транскрипції немає, повертається `TranscriptUnavailableError`,
а не перша доступна мова. `TranscriptLanguageError` означає неправильну
мову або недостатні метадані для її перевірки. SerpApi-відповідь повинна
позначити рівно одну вибрану транскрипцію в `available_transcripts`.
Для запиту `en` дозволені також регіональні варіанти на кшталт `en-US`.

Час — приблизний початок словесного фрагмента в секундах, округлений до
мілісекунд. Він інтерполюється за довжиною фрагментів, а не визначається
з аудіо. Сегменти стабільно сортуються за початком; інтервал обрізається
на початку наступного сегмента. Однакові таймкоди допустимі, зокрема при
однаковому початку сегментів; час не повинен зменшуватися. Точність до
мілісекунд у форматі не означає фактичну точність вимовляння слова.
Нескінченні, від'ємні або перевернуті часові інтервали відхиляються.

Перевірки: `python -m unittest discover -s tests -v`.
`tests/test_parser_integration.py` перевіряє відповіді провайдерів через фікстури
та викликає справжні перетворення парсера й CEFR-аналізатор без мережі/ключів.
`parser_test.py` — ручний живий тест, він не виконує запити під час імпорту.
